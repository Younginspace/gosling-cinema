GOSLING CINEMA 1 / 7

起源：一段录屏和一个念头

看到 shader.se 的复古 CRT 启动 + 3D 胶卷交互后，第一秒就觉得：这种胶卷形式太适合做演员作品集了。

正好最近因为《挽救计划》电影对 Ryan Gosling 印象深刻——五部电影，五种完全不同的视觉风格，天然适合用不同的 shader 来呈现。

"先行动，从被激发灵感的创意开始。创意是原创-复刻融合微创新的螺旋上升。" — 开发者
Core Idea

不是复制 shader.se，而是借鉴范式，用高司令五部代表作做一个有电影感的沉浸式体验。

协作方法：录屏驱动

录屏 (mp4)
  → AnyCap CLI + Gemini
  → 结构化描述 (md)
  → Claude Code
  → 代码
01
视频 > 截图：截图丢失时序、缓动、物理感。录屏的信息密度高一个量级
02
不求完全还原：AI 基于理解做出的"另一种版本"，可能比刻意复刻更有价值
03
分析文档即 Prompt：把 Gemini 的分析直接喂给 Claude Code 作为上下文，效果最好
GOSLING CINEMA 5 / 7

五条收获

01

先行动

看到灵感那一刻就开始。创意是螺旋上升的——先复刻，再理解，最后变成自己的东西

02

不完全还原也是成功

3D 旋转木马和 shader.se 长得完全不一样——但那种电影感和沉浸感是对的

03

真实内容是魔法

占位符变真实视频的那一刻，项目从"技术 demo"变成"作品"

04

CRT Boot 不只是装饰

它掩盖了加载时间，把等待变成体验。好的 loading 不是进度条，是叙事

05

Shader 参数是最廉价的氛围引擎

6 个浮点数就能让同一个画面从霓虹朋克变成赛博荒漠，比改模型便宜一百倍
